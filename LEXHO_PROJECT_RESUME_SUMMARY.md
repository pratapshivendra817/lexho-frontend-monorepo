# Lexho Frontend Monorepo - Resume Summary

## Short Project Summary

Worked on a scalable multi-app frontend monorepo for Lexho, covering an admin web panel and two React Native mobile applications for customers and service partners. The platform supports service discovery, booking and cart flows, payments, live dispatch and tracking, push notifications, partner operations, and role-specific business workflows through shared packages and reusable frontend architecture.

## Resume-Ready Version

Built and maintained a multi-application frontend monorepo for an on-demand services platform, including:
- an admin web dashboard for operations, bookings, dispatch, notifications, payments, banners, categories, and partner management
- a customer mobile app for authentication, location-based service discovery, cart, booking, payments, tracking, and support flows
- a partner mobile app for order handling, live operations, location updates, notifications, and partner workflow management

Used React, Vite, React Native, TypeScript, Redux Toolkit, React Query, Firebase, Mapbox, WebRTC, and shared workspace packages to create reusable, scalable, and contract-aligned frontend systems across web and mobile applications.

## Key Highlights For Resume

- Architected and contributed to a Yarn workspaces monorepo with shared packages for API, auth, hooks, constants, UI, and utilities.
- Developed and maintained an admin panel using React, Vite, React Router, React Query, MUI, Mapbox, and Firebase.
- Built and improved React Native customer and partner apps with Redux Toolkit, React Navigation, React Query, Firebase Messaging, Mapbox, and native Android integrations.
- Worked on real-world product modules such as booking lifecycle, live dispatch tracking, cart and checkout, payment flows, push notifications, partner operations, and content/configuration management.
- Improved frontend and backend contract alignment across multiple apps by tracing API payloads, normalizing response shapes, and handling fallback routes and edge cases.
- Added testing and reliability improvements using Vitest for web and Jest for mobile apps, along with targeted debugging for runtime, network, and device-specific issues.
